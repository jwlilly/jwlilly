# Hi, I'm John Lilly

I build tools for testing and improving accessibility on Android.

## Projects

- [Android Accessibility Inspector](https://github.com/jwlilly/Android-Accessibility-Inspector-App): a desktop app for inspecting the accessibility node tree of Android apps, the way a screen reader sees it.
- [Accessibility Inspector Service](https://github.com/jwlilly/Accessibility-Inspector-Service): the companion Android app that exposes the accessibility tree to the inspector.
- [FocusVisible](https://github.com/jwlilly/FocusVisible): a simple Android accessibility service that highlights the item with keyboard focus.
- [Bookmarklets](https://jwlilly.github.io/): accessibility testing bookmarklets for the web.
